## 🛒 M.JayaEswar Ventures — Founder & Operator *(2026 – Present)*

> I set up and run **M.JayaEswar Ventures**, the parent brand for four e-commerce storefronts that sell across Europe in euros. I chose the platforms, named the brands, connected the suppliers, built the catalogues and storefronts, and audited every store as a customer before go-live — the same supply-chain, operations and data discipline I bring to my analytics roles, applied to a business I own end to end.

## ✅ Stage 1 — Setup *(complete, 12 Oct 2026)*

| Area | What I did | Result |
|---|---|---|
| 🏷️ **Brand architecture** | Parent brand + four store brands; replaced names that weren't unique (e.g. a taken .com) | 1 parent brand · 4 distinct storefront brands |
| 🌍 **Market & pricing** | Moved the target market to all of Europe with EUR as default currency on every store | One market, one currency across the group |
| 🌐 **Domain** | Bought and connected **enjoyvo.com** to the flagship store | Branded URL instead of a platform sub-domain |
| 📦 **Catalogue & suppliers** | Supplier apps first, IndiaMart / Alibaba as second source, Printful for print-on-demand; disabled raw/demo imports instead of publishing them | **156 live products** on the flagship (150+ trust target met) across **10 categories** |
| 🔍 **Catalogue QA** | Crawled every flagship product's options; logged single-value required options and mislabelled variants for clean-up | Fix list ready with product IDs |
| 🛡️ **Trust layer** | Trust info blocks, "all in one place" banner, real contact page, secure-checkout block, rebuilt footer (14 working links), template brand names removed | No placeholder content on the storefront |
| 🤖 **Anti-spam** | Captcha on register, reviews, contact and returns; an existing bot account removed | New bot sign-ups blocked |
| 🧪 **Customer-eye audit** | Anonymous mystery-shopper run across all 4 stores + the parent site: home, product, cart, checkout, policies, search, mobile | Readiness verdict + blocker list per store |
